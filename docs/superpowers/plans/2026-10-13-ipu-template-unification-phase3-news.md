# ipu.co.in Template Unification: News Articles and News Index Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the generated news pages (about 95 articles plus the `/news/` index) onto the unified shell: shared hero with category pill, body grid with one enquiry form, `<details>` FAQ, orange CTA card, correct mobile order, human-readable dates, without changing any title, meta description, canonical or JSON-LD content.

**Architecture:** News pages are generated by `scripts/build-news.php` into `website_download/news/*.php`, each a 3-line file that includes `include/news-template.php` with a `$post` array. Changing the template changes every article at once and, once merged to `main`, the news workflow republishes them all. So the new layout lands behind a default-off switch (`NEWS_LAYOUT`, overridable by the `NEWS_LAYOUT` environment variable for tests), is verified against a baseline captured from the live pages, and the switch is flipped in a separate final commit that the owner gates.

**Tech Stack:** PHP 8.5 includes, `scripts/build-news.php` (`news_build_all($content_dir, $web_dir)`), pytest with a temp site served by `php -S`, `php scripts/tests/run.php`, `scripts/seo_verify.py`.

**Spec:** `docs/superpowers/specs/2026-10-13-ipu-template-unification-design.md` (Phase 2, item 2). Predecessors: Phase 1 plan (foundation CSS, hero slots, `$cta_card`) and Phase 2 plan (`faq-details.php`, `.ipu-*` classes) must be complete.

## Global Constraints

- Everything in the Phase 1 and Phase 2 Global Constraints applies (no title/meta/canonical/JSON-LD content change except the list below; one `<h1>`; one `id="enquiry-form"`; form contract unchanged; no `.blog-details` class on `.ipu-*` layouts; `index.php`, `trust-bar.php`, `faq-section.php` untouched; commits end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`; never chain `git commit` after `;`).
- **Deploy hazard:** `.github/workflows/news-build-deploy.yml` triggers on pushes to `main` touching `website_download/include/news-*.php`, `scripts/build-news.php`, `content/news/**` and publishes every news page and `sitemap.xml`/`llms.txt`. Nothing in this plan is pushed or merged. The final flip commit is the only change that alters live output, and it is isolated so it can be held back.
- Allowed changes on news articles: (a) `og:site_name` from `IPU.co.in` to `IPU Admission Guide`; (b) `tel:9899991342` to `tel:+919899991342` wherever it appears (the plain-number form is not present in `news-template.php` today; the check is still made); (c) visible dates become `j F Y` (the `<time datetime>` ISO value is kept); (d) emoji `⚠` replaced by an inline SVG; (e) visible breadcrumb is `Home / News / {Category} / {full title}` and BreadcrumbList JSON-LD is unchanged (the handoff's "short title" is NOT used, because shortening would force a JSON-LD change).
- The urgent banner shows only when `is_urgent` is true and the post's `date_modified` (else `date`) is at most 7 days before the build date.
- Hold list: none of these pages.

## Review Focus

- The three JSON-LD blocks in the head (NewsArticle, FAQPage, BreadcrumbList) must be byte-identical to the live pages; the new FAQ markup must not emit a second FAQPage block.
- `body_html` is raw HTML from Markdown; splitting it for the intro/rest areas must never drop or reorder content, including posts with zero or one `<h2>`, posts whose first element is not a heading, and `<h2>` text inside code or attributes.
- Posts with no `faq`, no `tags`, no `image`, a very long title, `&`/quotes/unicode in the title, `date_modified` equal to or later than `date`, and `is_urgent` true/false must all render without PHP notices.
- On mobile the article must come BEFORE the sidebar (the old `order-1` pushed the sidebar above it), and the enquiry form must appear after the first section.
- The `/news/` index search and category filter JavaScript depends on `.blog-item[data-category][data-title]`, `#newsGrid`, `#noResults`, `.btn-cat[data-cat]`, `#newsSearch` and `.mid-cta-strip-col`; all must survive.

```python
"""Capture the live SEO baseline for every news article and the /news/ index."""
import json, re, sys, urllib.request
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]


def grab(html):
    body = html.split("</head>")[-1]
    g = lambda pat: (re.search(pat, html, re.S) or [None, None])[1]
    meta = {m[0]: m[1] for m in re.findall(r'<meta (?:property|name)="((?:og|twitter|article):[^"]+)" content="(.*?)"', html)}
    ld = [json.loads(x) for x in re.findall(r'<script type="application/ld\+json">(.*?)</script>', html, re.S)]
    return {
        "title": g(r"<title>(.*?)</title>"),
        "description": g(r'<meta name="description" content="(.*?)"'),
        "canonical": g(r'<link rel="canonical" href="(.*?)"'),
        "robots": g(r'<meta name="robots" content="(.*?)"'),
        "meta": meta,
        "h1": [re.sub(r"<[^>]+>", "", m).strip() for m in re.findall(r"<h1[^>]*>(.*?)</h1>", body, re.S)],
        "headings": [re.sub(r"<[^>]+>", "", m).strip() for m in re.findall(r"<h[23][^>]*>(.*?)</h[23]>", body, re.S)],
        "links": sorted(set(re.findall(r'href="([^"#][^"]*)"', body))),
        "jsonld": ld,
    }


if __name__ == "__main__":
    base = sys.argv[1] if len(sys.argv) > 1 else "https://ipu.co.in"
    idx = urllib.request.urlopen(f"{base}/news/", timeout=30).read().decode("utf-8", "replace")
    slugs = sorted(set(re.findall(r'href="/news/([a-z0-9-]+)\.php"', idx)))
    data = {"index": grab(idx)}

        data[s] = grab(urllib.request.urlopen(f"{base}/news/{s}.php", timeout=30).read().decode("utf-8", "replace"))
    (ROOT / "tests" / "fixtures").mkdir(exist_ok=True)
```

```php
function news_human_date(string $iso): string {
    $d = DateTime::createFromFormat('Y-m-d', $iso);
    return ($d && $d->format('Y-m-d') === $iso) ? $d->format('j F Y') : $iso;
}

/** Split body_html before its second <h2 (real tags only). Lossless: $intro . $rest === $html. */
function news_split_body(string $html): array {
    if (preg_match_all('/<h2[\s>]/i', $html, $m, PREG_OFFSET_CAPTURE) && count($m[0]) >= 2) {
        $cut = $m[0][1][1];
        return [substr($html, 0, $cut), substr($html, $cut)];
    }
    return [$html, ''];
}

function news_is_fresh(string $iso_date, int $days = 7, ?string $today = null): bool {
    $d = DateTime::createFromFormat('Y-m-d', $iso_date);
    if (!$d || $d->format('Y-m-d') !== $iso_date) return false;
    $t = new DateTime($today ?? 'today');
    return $d <= $t && $d->diff($t)->days <= $days;
}
```
