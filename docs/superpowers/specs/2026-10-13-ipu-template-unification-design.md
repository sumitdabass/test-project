# ipu.co.in template unification: design

Date: 2026-10-13
Status: draft for owner review
Source: design handoff `~/Downloads/design_handoff_ipu_template_unification/` (README.md, `IPU Page Templates.dc.html`, `ipu.co.in Consistency Audit.dc.html`)

## Goal

A visitor moving between the homepage, college, course, cutoff, blog and news pages sees the same header, hero, layout, enquiry form, call button and footer. Priorities, in order: (1) phone CTA, (2) enquiry form, (3) SEO intact, (4) user experience.

`website_download/index.php` is the visual reference and is never modified.

## Measured starting point (2026-10-13, 138 root PHP pages)

|---|---|
| Using `base-head.php` and `base-nav.php` | 97 |
| Not on the shared head/nav (older standalone pages) | ~41 |

| Using `cta-strip.php` | 46 |
| Using the college template | 30 |
| Legacy `blog-wrapper` body | 36 |

Nav, footer and sidebar are mostly shared. The drift is in the hero, the page body layout, the CTA strip colour and the news pages.

## Scope

In scope: shared CSS and hero upgrade; college pages; news article template and index; course admission, cutoff, management quota and top-colleges pages; the ~41 older standalone pages (last).

Out of scope: `index.php`; page copy, CTA labels, phone numbers, URLs, titles, meta descriptions, canonicals and JSON-LD content, except the explicit fixes listed under "Allowed content changes"; hours-string normalisation (every instance already says 9 AM to 7 PM, Mon to Sat, only formatting differs); adding B.Ed, LLB (3 Year), LLM and B.Arch to the shared course list (owner decision, not taken).

## Hold list

USAR, homepage and ADGIPS carry approved title/meta tests live from 1 Dec 2026 (rechecks 15 Dec and 29 Dec, decision 5 Jan; see `seo/rechecks/2026-12-01/decision.md`). Their titles, metas and H1s must not change. Template conversion of those three pages waits until after 5 Jan.

## Design

### Phase 1: foundation (one deploy, sitewide)

Additive only. No page markup changes, so existing pages should not shift.

- `base-head.php` critical CSS: add `*,*::before,*::after{box-sizing:border-box}`; tap targets at least 44px (primary CTAs 48 to 52px); inputs 16px (every form uses `.ipu-input`).
- `components/page-hero.php`: add the Enquire button (`href="#enquiry-form"`) and an optional meta-line slot; navy gradient `linear-gradient(135deg,#0d1b6e 0%,#1a3a9c 60%,#2a5ac8 100%)`; breadcrumb first; optional category pill (news). Call button `tel:+919899991342`, `#ff7a1a` with navy text, `data-cta-src="hero"`. The page H1 stays the only H1.
- `components/cta-strip.php`: button becomes orange `#ff7a1a` with navy text, pill radius, replacing the amber to gold gradient.
- `base-head.php`: remove the older `.mobile-call-cta` and `.mobile-call-btn` gradient rules so only the `base-nav.php` sticky bar styles apply.
- Add the shared body-grid CSS (`.ipu-body` with `intro`, `aside`, `rest` grid areas, sticky 360px sidebar from 992px). Defined here, used from phase 2.
- Replace emoji icons (👉 🔍 ⏰ 📞 ⚠) with inline SVG or plain link rows, link text verbatim, as pages are converted (not as a blind sitewide replace).

### Phase 2: page types, one deploy each

1. **College pages**: `BPIT.php` as the pilot, then `include/templates/college-page-template.php` and the 30 college pages. Single hero breadcrumb (Home / Colleges / BPIT College) matching the BreadcrumbList; remove the second visible breadcrumb and `pt-130 pb-130`; body grid; chip grid, numbered steps, course cards, tint cards, scrollable pinned-column tables; `rest` order Courses, Admission Process, CTA strip, Placement/Campus, Fee table, Cutoff table, FAQ, Compare, Related Guides. FAQ as `<details>` with H3 summaries, visible text identical to FAQPage JSON-LD (visible copy is the source of truth). The trailing "Need Admission Guidance?" block is kept, restyled as a second CTA strip.
2. **News article**: `include/news-template.php`, `news/index.php`, `scripts/build-news.php`. Shared hero with category pill and meta line; remove `.breadcrumb-wrap`; dates as `j F Y` with ISO kept in `<time datetime>`; replace `sidebar-cta.php` with `sidebar-enquiry.php`; remove the `order-2`/`order-1` classes that push the sidebar above the article on mobile; TL;DR card and urgent banner restyle (banner only when `is_urgent` and the post is 7 days old or less); `tel:9899991342` becomes `tel:+919899991342`; static "Counsellors online" dot. News output is regenerated by the news CI, so this ships as a deliberate, separate push after local build verification.
3. **Course admission, cutoff, management quota and top-colleges pages**: shared hero, body grid with `sidebar-enquiry`, CTA strip after the first major section, FAQ pattern, single breadcrumb. Converts the 33 to 36 legacy `blog-wrapper` pages.
4. **Older standalone pages (~41)**: last. Each page first moves onto shared `base-head`, `base-nav` and `base-footer`, then onto the body grid. One at a time or in small batches, since they have no shared structure to build on.

### Allowed content changes (explicit fixes only)

- BPIT: `$breadcrumbs` labels and URLs aligned to the hero breadcrumb; FAQPage JSON-LD aligned to the visible FAQ; add og:title, og:description, og:url, og:type, twitter:title and twitter:description from the existing title and meta description.
- News: `og:site_name` from `IPU.co.in` to `IPU Admission Guide`.
- `tel:9899991342` to `tel:+919899991342` wherever it appears.

## Safety rules (every phase)

- Run `scripts/seo_verify.py` and `php scripts/tests/run.php` before and after; diffs show only intended changes.
- Exactly one `<h1>` per page; H2/H3 text and order unchanged; visible breadcrumb equals BreadcrumbList; visible FAQ equals FAQPage; every internal link and anchor text preserved; images keep width/height and the hero image keeps `fetchpriority="high"`.
- Exactly one `id="enquiry-form"` per page; the form contract (`POST /sendemail.php`; `name, phone, email, course, page_url, website, form_loaded_at`) is unchanged.
- Trust bar is the `index.php` `trust-bar.php` verbatim.
- Localhost walk of nav, footer, sidebar and CTA links before every deploy. Checks must include JS-rewritten `route()` links (grep `setAttribute` and `.href=`).
- Deploys are file-scoped from a clean worktree: rsync the live copy to a backup first, `cmp` against git HEAD~1 for drift, upload, curl 200 and a fatal-error grep, then push. Pull live `sitemap.xml` and `.htaccess` before any edit, since the live copies are ahead of the repo. Merging to `main` publishes the news workflow immediately.
- No phase deploys without the owner's go.
